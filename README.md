# CHIMGAN DARBAZA

Сайт `chimgandarbaza.uz`: проживание, сезонные дневные услуги, ресторан, заявки и партнёрский раздел. Репозиторий: [Abdurasul99/chimgansoy_resort](https://github.com/Abdurasul99/chimgansoy_resort).

Next.js 16, React 19, TypeScript, Tailwind CSS v4, Postgres. Языки: `/ru`, `/uz`, `/en`. Панель оператора — `/admin`. Бронирование — Exely и отдельные формы заявок.

## Запуск и проверка

Нужны Node.js 22 и `.env.local`. Секреты выдаются отдельно, в Git не хранятся.

```sh
npm ci
npm run dev
# http://localhost:3000/ru
npx tsc --noEmit
npm test -- --maxWorkers=4
npm run build
```

Полные Windows-пути — в [AGENTS.md](./AGENTS.md). Для интеграционных тестов БД нужна отдельная тестовая база.

## Структура

| Папка | Назначение |
|---|---|
| `src/app/` | Страницы, админка, API и server actions |
| `src/components/` | Интерфейс |
| `src/content/` | Контент и настройки по умолчанию, три языка |
| `src/lib/` | БД, файлы, интеграции и логика |
| `public/` | Опубликованные медиа и документы |
| `scripts/` | Импорт медиа, миграции и инструменты бота |
| `tests/` | Общие настройки, интеграционные и браузерные проверки |
| `docs/` | Документация и аудит папки |

В Hotel также находятся отдельные репозитории `chimgan-link/` и `chimgan-uslugi/`, исходные фото и закрытые пакеты передачи. Они исключены из Git основного сайта.

## Документация и публикация

Начните с [карты документации](./docs/README.md). Правила для ИИ — [AGENTS.md](./AGENTS.md); `CLAUDE.md` ссылается на тот же файл.

Код и сентябрьская документация описывают размещение на Contabo. Старые инструкции Vercel и Bnovo относятся к прошлым версиям. Перед публикацией проверьте действующую конфигурацию сервера; Git push сам по себе не подтверждает обновление сайта.
