## Локальные материалы

Основная папка передачи в корне Hotel: `Инструкия Сайта Chimgan Darbaza/`. Содержит PDF, Markdown, архивы кода и инструкции Contabo. В ней есть закрытые материалы с доступами; она исключена из Git. Отличающаяся версия PDF ресторана из облачного пакета и пояснение к паролям сохранены в подпапке `Варианты облачного пакета/`.

`CHIMGAN/` — ранний пакет передачи с уникальными файлами. `Hotel_photo/` — исходные фото. PDF о возможностях сайта сохранён в корне. PDF и Markdown, оригиналы фотографий и обработанные версии считаются разными материалами.

Актуальное поведение определяется кодом и настройками админки. Пароли и ключи — в закрытом пакете и окружении сервера. Архивные документы отражают свою дату; сведения о дневном формате, отсутствии БД, Vercel и заказах ресторана могут расходиться с текущим кодом.
