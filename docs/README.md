## Локальные материалы

Единственная папка передачи — `Инструкия Сайта Chimgan Darbaza/` в корне Hotel: PDF 00–11 с исходниками в Markdown, документы сайта (PDF, Markdown и Word-оригиналы в `Документы сайта/Исходники (Word)/`), инструкция оператору с PDF о возможностях сайта. В ней есть закрытые материалы с доступами; она исключена из Git. Копий кода в ней нет: код — в этом репозитории и в `chimgan-link/`, как сделать свежую копию для передачи — `Код/КАК РАСПАКОВАТЬ.md`. В `Варианты облачного пакета/` осталось только пояснение, почему пароли не кладут в облако.

`Hotel_photo/` — CGI-рендеры генплана от оператора (март 2026), не фотографии. На сайт не ставить: с 4 августа 2026 на сайте только реальные фото. Ранний пакет `CHIMGAN/`, июльский архив документов и старые архивы деплоя удалены 17.11.2026 как устаревшие копии — см. [WORKSPACE-AUDIT.md](./WORKSPACE-AUDIT.md).

Актуальное поведение определяется кодом и настройками админки. Пароли и ключи — в закрытом пакете и окружении сервера. Архивные документы отражают свою дату; сведения о дневном формате, отсутствии БД, Vercel и заказах ресторана могут расходиться с текущим кодом.
